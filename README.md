# mini_check

`mini_check`는 **아주 작은 행동을 쉽게 시작하고, 쉽게 완료하도록 돕는 미니 체크 앱**입니다.

이 프로젝트는 “완성도 높은 상용 서비스”보다는  
**올바른 구조, 명확한 상태 관리, 유지 가능한 UI 설계**를 목표로 하는 개인 Flutter 프로젝트입니다.

---

## 🎯 프로젝트 목표

- 작은 행동(1~5분 단위)을 부담 없이 기록하고 실행할 수 있도록 돕는다
- 기능 추가보다 **구조와 설계의 일관성**을 우선한다
- UI는 화려함보다 **명확함과 사용성**을 기준으로 한다
- 개인 프로젝트이지만 **실제 앱스토어 배포를 목표**로 한다

---

## 🧭 핵심 컨셉

- **One Screen, One Action**
  - 한 화면에서는 하나의 핵심 행동만 수행할 수 있도록 설계
- **Low Friction**
  - 입력, 완료, 이동에 불필요한 단계를 만들지 않는다
- **Minimal UI**
  - 색상, 애니메이션, 컴포넌트 수를 최소화한다

---

## 📱 주요 기능 (예정)

- 오늘의 체크 항목 목록
- 체크 항목 추가 / 완료
- 진행 상태 표시
- 간단한 타이머 또는 소요 시간 기록
- 로컬 저장 기반 상태 유지

> ※ 기능은 필요에 따라 점진적으로 추가하며  
> “구조가 망가지지 않는가?”를 항상 먼저 검토한다.

---

## 🧩 UI 설계 기준

- 플랫폼 기본 가이드(Material / iOS HIG)를 최대한 따른다
- 커스텀 UI는 **필요한 경우에만 최소 단위로 구현**
- 시안 없이 시작하며, **정보 구조 → 동작 → 스타일** 순으로 완성한다

---

## 🛠 기술 스택

- Flutter (Stable)
- Dart
- 상태 관리는 단순한 구조부터 시작
- 외부 패키지는 꼭 필요한 경우에만 도입

---

## 🚧 개발 원칙

- “일단 동작”보다 **“이유 있는 구현”**
- 임시 코드라도 **왜 임시인지 설명 가능해야 한다**
- 복잡해지기 시작하면 즉시 구조를 다시 정리한다

---

## 🤝 이 프로젝트의 개발 방식

이 프로젝트는 다음과 같은 방식으로 진행됩니다.

1. 기능 단위로 목표를 정한다
2. UI 구조를 먼저 텍스트로 정의한다
3. 최소한의 코드로 동작을 만든다
4. 그 후 구조와 책임을 다듬는다
